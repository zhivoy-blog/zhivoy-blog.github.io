# «Живой ИИ: Контроль» — запуск приложения

Личный PWA-трекер контент-проекта. Установлен как обычная страница сайта,
но по скрытому адресу и без ссылок из навигации: `/shtab-d14558/`.

Полный адрес после публикации: `https://zhivoy-ai.ru/shtab-d14558/`

## Что нужно сделать один раз перед первым запуском

### 1. Создать приватный репозиторий для данных

Черновики постов, история и счётчики хранятся отдельно от публичного сайта,
чтобы они не были видны всем. Создайте **приватный** репозиторий:

1. https://github.com/new
2. Владелец: `zhivoy-blog`, имя: `zi-control-data` (можно другое — впишете
   его в настройках приложения).
3. Video/Visibility: **Private**.
4. «Create repository» — больше ничего внутри создавать не нужно,
   приложение само заведёт нужные файлы при первом подключении.

### 2. Создать токен доступа GitHub (Personal Access Token)

1. https://github.com/settings/tokens?type=beta → «Generate new token»
   (Fine-grained), или классический https://github.com/settings/tokens/new.
2. Дайте доступ на запись (**repo**, contents: read & write) к двум
   репозиториям: `zhivoy-blog/zi-control-data` (данные) и
   `zhivoy-blog/zhivoy-blog.github.io` (сайт — нужен для переноса статей и
   картинок при публикации).
3. Скопируйте токен — он показывается один раз. Вставьте его в приложении,
   вкладка «Настройки» → «GitHub Personal Access Token».

Токен хранится только в браузере этого устройства (localStorage) и нигде
не публикуется.

### 3. Развернуть бэкенд для почты и публикации

Статический сайт сам не может читать Gmail и стучаться в Telegram/ВК API —
для этого нужен лёгкий бэкенд на Google Apps Script. Подробная пошаговая
инструкция: [`apps-script/README.md`](apps-script/README.md).

Коротко: разворачиваете код из `apps-script/Code.gs` как Web App в
аккаунте `kypatop5@gmail.com`, получаете URL и придуманный вами секретный
токен — вписываете в приложении, вкладка «Настройки».

### 4. Первый запуск

1. Откройте `https://zhivoy-ai.ru/shtab-d14558/` на телефоне/планшете.
2. «Добавить на экран Домой» (Safari: Поделиться → На экран «Домой»;
   Chrome/Android: предложит установить сам).
3. При первом входе приложение попросит **придумать пароль** — он
   хранится только на этом устройстве и защищает страницу от случайных
   посторонних (страница не в навигации сайта и не индексируется, но сама
   по себе не зашифрована — не показывайте адрес чужим).
4. Откройте «Настройки», заполните все поля из шагов 1–3 выше, нажмите
   «Проверить подключение к GitHub» и «Проверить соединение» (Apps
   Script) — оба должны показать ✓.
5. На вкладке «Сегодня» нажмите «Обновить» — приложение заберёт письма с
   готовыми постами по расписанию.

На каждом новом устройстве (втором телефоне, планшете) шаги 2–4
повторяются — данные общие (в GitHub), но токены и пароль у каждого
устройства свои.

## Важно понимать про «перенос на сайт»

Кнопка «Подготовить рерайт» в редакторе поста делает **черновой**
авто-рерайт (убирает форматирование под соцсети, расставляет абзацы,
подставляет обложку/картинки, предлагает заголовок, URL и описание для
SEO) — это не полноценный ИИ-рерайт (для него потребовался бы отдельный
платный API вроде OpenAI/Claude, который не был подключён). Черновик
редактируется прямо в приложении перед публикацией — как и просилось в
задаче: сначала подготовка, потом ваше подтверждение кнопкой.

## Структура приложения в репозитории сайта

```
shtab-d14558/        — сама PWA (скрытый путь, исключён из robots.txt)
  index.html, app.css, app.js, github-store.js
  manifest.webmanifest, sw.js, icons/
apps-script/          — код бэкенда + инструкция по развёртыванию
  Code.gs, README.md
```

Данные проекта (посты, счётчики) находятся не здесь, а в отдельном
приватном репозитории `zhivoy-blog/zi-control-data` (файлы `posts.json`,
`counters.json` — заводятся автоматически при первом подключении).
