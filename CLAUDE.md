# Живой ИИ — zhivoy-ai.ru

Сайт блога «Живой ИИ» (автор — Вадим). GitHub Pages, обычный HTML/CSS/JS, без CMS и без сборки.
Домен через `CNAME`. Всё, что лежит в `main`, сразу публикуется на сайте.

## Как устроен сайт

- `index.html` — главная: лента статей из `articles/manifest.json`, поиск, фильтр по рубрикам.
  Рубрики = кнопки `.tag-filter`: `музыка`, `промпты`, `тексты`, `реальные-истории`.
  Статья с другой рубрикой не попадает ни в один фильтр.
- `articles/<slug>/` — одна статья: `data.json`, `index.html`, картинки и видео рядом.
  - `data.json` — ровно 5 полей: `title`, `date` (ГГГГ-ММ-ДД), `tag`, `excerpt` (описание для поиска и соцсетей), `content` (HTML статьи).
  - Пути к медиа в `content` — только имя файла рядом (`src="cover.jpg"`), без папок.
  - `index.html` — страница с мета-тегами этой статьи; текст подгружается из `data.json`.
- `articles/manifest.json` — оглавление для главной, новые сверху.
- `sitemap.xml`, `robots.txt` — для поисковиков. Каждая статья должна быть в `sitemap.xml`.
- `article-template.html` + `article-script.js` — старая схема `article-template.html?article=<slug>`.
  Больше не используется для новых статей, но **не удалять**: по ней работают старые ссылки.
  `article-script.js` к тому же нужен каждой странице статьи.
- `tools.html` — страница инструментов, категории: картинки, аудио, видео, PDF, текст. Всё считается
  в браузере посетителя, файлы никуда не отправляются. Видео и «В MP3» — через ffmpeg.wasm
  (`js/vendor/ffmpeg`, общий `VideoKit`), громкость MP3 — через `js/vendor/lame.min.js`,
  PDF — через pdf-lib с CDN (общий `PdfKit`); QR-код (qrcode-generator), данные в фото (exifr) и
  текст с картинки (tesseract.js) — библиотеки с CDN через `loadLibOnce`. Примеры для кнопок
  «Попробовать на примере» — в `audio/` и `img/`. Прямые ссылки: `tools.html#pdf` (категория),
  `tools.html#tomp3` (инструмент).
- `site-chrome.css` / `site-chrome.js` — общая шапка, бургер-меню, подвал, кнопка «Мы в ВК».
- `shtab-d14558/` — скрытое приложение «Живой ИИ: Контроль» (PWA автора). Без ссылок из навигации, в `sitemap.xml` не добавлять.
  В `app.js` лежит **единственный шаблон страницы статьи** (`buildArticlePageHtml`).
- `apps-script/` — бэкенд приложения на Google Apps Script.

## Скрипты (Node 18+, без установки пакетов)

| Команда | Что делает |
|---|---|
| `node scripts/new-article.mjs <slug> [<slug> …]` | Проверяет `data.json` и файлы, создаёт `index.html` по шаблону из `app.js`, добавляет статью в `manifest.json` и `sitemap.xml`. Существующий `index.html` не трогает без `--force`. |
| `node scripts/check-site.mjs` | Проверяет все статьи: страницы, картинки, `sitemap.xml`, дубли, даты. Код выхода 1 — есть ошибки. |
| `node scripts/count-chars.mjs post.txt` | Считает знаки поста и сверяет с лимитами Telegram, проверяет хэштеги и тире. |

## Правила работы

- После любых изменений в статьях — `node scripts/check-site.mjs`. Работа не готова, пока в нём есть ошибки (✗).
- Длину поста считать только скриптом `count-chars.mjs`, не «на глаз».
- Не менять дизайн, палитру и общие стили без явной просьбы. Картинка внутри статьи
  никогда не должна вылезать за карточку — это правило в стилях не трогать.
- Приложение «Контроль» при переносе статьи **не добавляет её в `sitemap.xml`** — после его публикаций запускать `check-site.mjs` и дописывать.
- Инструменты в `tools.html` работают только в браузере, без серверов и отправки файлов. Проверять на ширине телефона (~375 px).
- Тексты на сайте — простым языком для новичков 35–55 лет, термины объяснять в скобках.

## Для постов (Telegram / ВК / vc.ru)

- `docs/kopilka-golosa.md` — копилка слов и оборотов Вадима и список «не подошло». Главнее словаря в скиле `golos-vadima`.
- `docs/zhurnal-postov.md` — журнал последних постов: тема, формат, просьба о лайке, вопрос в конце. Перед новым постом читать, после — дописывать строку.
- `docs/skills/` — актуальные тексты скилов (копии для загрузки в claude.ai и для истории правок).
