# Настройка бэкенда (Google Apps Script)

Бэкенд нужен, чтобы приложение «Живой ИИ: Контроль» могло читать письма из
`kypatop5@gmail.com` и публиковать посты в Telegram/ВКонтакте — статический
сайт сам по себе делать это не может. Скрипт разворачивается один раз, в
вашем собственном Google-аккаунте, и работает от вашего имени.

## 1. Создайте проект Apps Script

1. Откройте https://script.google.com **под аккаунтом kypatop5@gmail.com**.
2. «Новый проект».
3. Удалите содержимое `Code.gs` по умолчанию и вставьте содержимое файла
   `Code.gs` из этой папки репозитория.
4. Переименуйте проект, например «Живой ИИ: Контроль — бэкенд».

## 2. Задайте Script Properties

В редакторе: значок шестерёнки слева → «Project Settings» → раздел
«Script Properties» → «Add script property». Добавьте:

| Свойство | Значение |
|---|---|
| `APP_TOKEN` | придумайте длинную случайную строку — это пароль между приложением и скриптом |
| `TELEGRAM_BOT_TOKEN` | токен бота, см. ниже |
| `VK_TOKEN` | access_token сообщества, см. ниже |

Необязательные (можно не добавлять, будут значения по умолчанию):
`GMAIL_QUERY`, `PROCESSED_LABEL` (по умолчанию `ЖИ-обработано`), `VK_API_VERSION`.

## 3. Письма с постами находятся сами — по теме письма

По умолчанию скрипт ищет письма по теме («Утренний пост Telegram»,
«Вечерний пост Telegram», «Пост ВКонтакте», «Пост vc.ru») — размечать
письма ярлыком вручную не нужно, это происходит автоматически при
каждой синхронизации.

Если письма приходят с другой темой или их нужно найти иначе (например,
по отправителю) — задайте свойство `GMAIL_QUERY` (обычный поисковый
запрос Gmail). Можно совмещать с ярлыком `ЖИ` (например, если хотите
иногда добавлять письма вручную) — значение по умолчанию как раз это
делает:

```
(label:ЖИ OR subject:"Утренний пост Telegram" OR subject:"Вечерний пост Telegram" OR subject:"Пост ВКонтакте" OR subject:"Пост vc.ru") -label:ЖИ-обработано
```

**Если скрипт уже был развёрнут раньше** (до этого обновления) — новая
логика поиска по теме заработает, только если вручную добавить свойство
`GMAIL_QUERY` со значением выше (Project Settings → Script Properties).
Переустанавливать код `Code.gs` для этого не нужно.

## 4. Создайте Telegram-бота (опционально)

Публикация в Telegram/ВК в приложении делается вручную — кнопкой
«Скопировать», без бота. Этот шаг нужен, только если захотите включить
**автоматический счётчик подписчиков** (вкладка «Счётчики»). Можно
пропустить и вернуться к нему позже.


1. В Telegram напишите **@BotFather** → `/newbot`, следуйте инструкциям.
2. Полученный токен вида `123456:AA...` — это `TELEGRAM_BOT_TOKEN`.
3. Добавьте бота **администратором** в ваш канал (с правом публикации сообщений).
4. chat_id канала — это `@username_канала` (если публичный) либо числовой
   id вида `-100...` (если приватный; узнать можно через @userinfobot или
   пересылкой сообщения боту @getidsbot). Впишите его в приложении на
   вкладке «Настройки».

## 5. Получите токен ВКонтакте (опционально, тоже только для счётчика)

1. Создайте Standalone-приложение на https://vk.com/apps?act=manage (или
   используйте существующее сообщество и его «Ключ доступа сообщества»:
   Управление сообществом → Работа с API → Ключи доступа → создать ключ с
   правами **стена, фото**).
2. Полученный `access_token` — это `VK_TOKEN`.
3. id сообщества (число без минуса) впишите в приложении на вкладке
   «Настройки».

## 6. Разверните Web App

1. «Deploy» → «New deployment».
2. Тип: **Web app**.
3. Execute as: **Me (kypatop5@gmail.com)**.
4. Who has access: **Anyone**.
5. «Deploy», разрешите запрашиваемые доступы (Gmail, внешние запросы) —
   это доступ для скрипта в вашем собственном аккаунте, он никому больше
   не передаётся.
6. Скопируйте URL вида `https://script.google.com/macros/s/…/exec` —
   вставьте его вместе с `APP_TOKEN` в приложении, вкладка «Настройки».

## Обновление скрипта

Если правите `Code.gs`, после сохранения сделайте **Deploy → Manage
deployments → редактировать (карандаш) → New version → Deploy** — иначе
рабочий URL продолжит использовать старую версию кода.
