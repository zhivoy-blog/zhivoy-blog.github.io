# Самопроверка перед выдачей

Этот скилл — последний шаг. Он не пишет текст, а проверяет, что всё из других скиллов реально сделано, а не «вроде сделано». Отдавать пост Вадиму можно только после него.

## 1. Проверки уже пройдены?

Убедись, что в этой работе действительно были шаги (не по памяти, а по тому, что ты сделал в этом разговоре):

- факты — через `fact-checker`, с источниками, которые ты реально открыл (для историй и любых цифр, дат, цитат);
- голос — «Проверка перед выдачей» из `golos-vadima`;
- `humanizer`.

Если какого-то шага не было — сделай его сейчас, а не отмечай галочкой.

## 2. Посчитай, а не прикинь

Сохрани текст поста в файл и запусти в репозитории сайта:

```
node scripts/count-chars.mjs пост.txt
```

Скрипт показывает число знаков, лимиты Telegram (1024 / 2048 / цель 1000–1100), лишние и недостающие хэштеги, избыток тире и слово «прикинь». Если репозитория нет, посчитай длину кодом и напиши, чем считал. Писать «примерно 1000 знаков» без подсчёта нельзя.

## 3. Сверь с журналом

Открой `docs/zhurnal-postov.md` (последние 10 строк):

- тема не повторяет недавний пост;
- просьба о лайке не совпадает с прошлыми даже по смыслу одной фразы;
- вопрос в конце и варианты ответов не те же, что были.

## 4. Перечитай глазами читателя

Один раз прочитай пост целиком как человек 35–55 лет, который впервые открыл нейросеть:

- понятно ли каждое слово без поиска в интернете;
- работает ли промт, если скопировать его как есть (для лайфхака — мысленно выполни его и посмотри, что получится);
- нет ли выдуманного: цифр, цитат, имён, дат, которых нет в источнике.

## 5. Отчёт Вадиму

Под постом — короткий блок, не длиннее 6 строк:

```
Проверка:
✓ факты: 4 из 4 подтверждены (источники выше)
✓ знаков: 1043 (Telegram Premium — влезает, обычный — нет)
✓ хэштеги: три нужных
✓ лайк и вопрос не повторяют прошлые посты
⚠ <что осталось сомнительным, если есть>
```

Если хоть один пункт ✗ — сначала исправь, потом отдавай. Если исправить нельзя (нет источника, нет доступа к журналу), так и напиши в отчёте, не скрывай.

## 6. После одобрения

Когда Вадим одобрил пост, допиши строку в начало таблицы `docs/zhurnal-postov.md`: дата, площадка, формат, тема, дословная просьба о лайке, вопрос и варианты. Новые обороты, которые Вадим подтвердил, — в `docs/kopilka-golosa.md`.
