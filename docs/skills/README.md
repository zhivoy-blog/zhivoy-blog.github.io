# Скилы «Живого ИИ»

Здесь лежат актуальные тексты скилов. Claude читает скилы из аккаунта claude.ai, а не отсюда, поэтому после правок здесь их нужно обновить в аккаунте.

Как обновить скил: в настройках claude.ai откройте раздел со скилами, выберите нужный и замените его текст на `SKILL.md` из этой папки. Новый скил — добавить и загрузить `SKILL.md`.

Зачем копия в репозитории: видно историю правок (что и когда поменяли), а если что-то сломается, можно вернуть прежнюю версию.
